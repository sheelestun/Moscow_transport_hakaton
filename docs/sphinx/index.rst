Предиктор задержек наземного транспорта Москвы
================================================

Система прогнозирует фактическое время прибытия наземного транспорта Москвы
(автобусы, троллейбусы, электробусы, трамваи) по потоку NDTP-телеметрии.
На вход — план рейса и последние GPS-фиксы, на выход — прогноз задержки
на целевой остановке в секундах.

Полное описание проекта, инструкции по запуску и структуру репозитория
смотрите в корневом ``README.md`` (`ссылка на файл <../../README.md>`_).
