# Статистика датасета

Начните с [отчёта](REPORT.md). Для просмотра всех графиков на одной странице откройте локально [index.html](index.html). GitHub отображает Markdown и PNG; HTML нужно скачать вместе с `figures/` и открыть в браузере.

## Воспроизведение

Python 3.12+. Выполнять из корня репозитория:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -r statistics/requirements.txt
python statistics/analyze.py --dataset ./msc_hak
python -m unittest discover -s statistics/tests -v
```

Можно указать `--dataset ./dataset` или переменную окружения `DATASET_DIR`. Без аргумента и переменной используется `./dataset`. Датасет скачивается отдельно по инструкции в корне репозитория. В нём должны быть `train/`, `test/`, `validate/`, `labels/` и `sample_submission.csv`.

Результаты по умолчанию записываются рядом со скриптом. Для отдельного прогона используйте `--output <папка>`, не совпадающую и не вложенную в папку датасета (и наоборот). Запуск не изменяет исходные CSV и не обращается в сеть. Обработка использует полные данные в памяти. Повторный запуск с теми же входами, версиями библиотек и seed воспроизводит результаты; PNG могут отличаться метаданными между платформами.

## Содержимое

- `analyze.py` — загрузка, проверки, агрегаты и генерация отчёта.
- `plots.py` — raincloud, UpSet и диагностические графики.
- `REPORT.md`, `index.html` — результаты и интерпретация.
- `figures/` — PNG для просмотра в GitHub и локально.
- `tables/` — только агрегаты: размеры, NULL, квантили, флаги, пересечения, baseline и проверки.
- `manifest.json` — относительные имена, SHA-256 источников, версии библиотек и методика.
- `tests/` — проверки временных границ, отсутствующей истории и контроль качества.

Не включаются исходные строки телеметрии, расписания, разметки, Docker-образ, модели или восстановленные ответы validate. Точки raincloud показывают только значения распределения без sample_id, tr_id или координат.

Важно: `statistics/` — папка аналитики, а не Python-пакет; запускайте скрипт по пути, не через `python -m statistics` (это имя стандартного модуля Python).

## Источники

Определения полей и правила горизонта: локальный README раздачи и `docs/Emulator-and-Telematic-Packets-Specification.md` внутри датасета. Исходная раздача: [Яндекс.Диск](https://disk.yandex.ru/d/CA6tsj4aJJ4Aaw). Каждый CSV текущего прогона идентифицирован хешем в manifest.

Анализ описательный: диагностические пороги не применяются как очистка, данные между split не объединяются для оценки модели, официальная метрика платформы не подменяется локальным приближением.
